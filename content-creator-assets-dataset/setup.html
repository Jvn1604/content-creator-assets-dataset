Wire this dataset into your own stack

The dataset lives as flat JSON at data/assets.json — no server required to browse it. If you want to load it into a database or hit it from an app, use the generated schema and client snippets below. Copy, paste, adjust to taste.

1Field reference

Every record in data/assets.json follows this shape.

FieldTypeNotes
idintegerUnique record id, 1–50
namestringAsset name
categoryenumoverlay · transition · lower-third · alert · panel · intro-outro · font
style_tagsstring[]Aesthetic tags, e.g. cyberpunk, retro-vhs
platformsstring[]Twitch, YouTube, TikTok, Kick
color_palettestring[]4 hex codes, background → accents
font_familystring | nullSet for font/lower-third/alert entries
effect_notesstringShadow/glow/stroke treatment
animation_typeenumfade · slide · glitch · particle-burst · wipe · zoom-punch · static
use_casestringRecommended stream context
descriptionstringFree-text description
retention_tierenumHigh · Medium · Low — illustrative annotation, not measured analytics
retention_rationalestringReasoning behind the tier annotation
preview_imagestringRelative path to generated SVG preview

4Regenerate or extend the dataset

    
The dataset and its SVG previews are procedurally generated from two scripts, so you can add new entries without hand-drawing anything.

    

      

        terminal
        
      

      
# Edit ASSET_SEEDS in generate_data.py, then:
python3 generate_data.py       # rebuilds data/assets.json
python3 generate_previews.py   # rebuilds assets/previews/*.svg
